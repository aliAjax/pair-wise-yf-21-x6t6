# 染槽排产台（地毯修复工坊）

源提示词编号：2 · 端口 62009

几家地毯修复工坊共用染线槽，馆藏借展和私人订单常为同一色卡批次抢槽，染机停机后还会互相顶单。本排产台把**纹样档案、修复批次、材料色卡、染槽槽位**接起来：

- **排产台（甘特图）**：同一槽位同一时段只容纳一个批次，按加急（特急/加急/普通）顺序占位；容量满时保留交期继续排队。
- **染机停机/维护**：未开始批次释放占用，按剩余容量顺延重排；已染好的照旧入库。
- **外协回执对账**：按批次号与本院记录对账；色卡批次或用量不一致先留待处理；迟到/重复回执不改写已确认工序。
- **旧数据升级**：缺交期/槽位号的旧档案自动补为普通单、状态置为待分配，原记录仍可打开。

## 技术栈

React + Vite + TypeScript，数据存于浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```
